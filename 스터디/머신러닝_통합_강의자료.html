CHAPTER 01

AI · ML · DL — 무엇이 무엇을 포함하는가

셋은 나란한 개념이 아니라 포함관계입니다. 이것이 이 강의 전체의 출발점입니다.

정의 · AI

AI (Artificial Intelligence)

주어진 환경/데이터를 인지·학습·추론을 통해 목표 달성을 하도록 예측 · 행동 선택 · 계획하는 시스템

정의 · ML

ML (Machine Learning)

AI 범주 내에서 데이터로부터 학습하여 목적을 달성하는 접근 방법론

생성형 AI언어 모델 이미지 분류 모델추천 시스템
정의 · DL

DL (Deep Learning)

ML 범주 내에서 신경망(Neural Network) 함수를 사용한 학습 방법론

주의 · AI인데 ML이 아닌 것

AI − ML (ML이 아닌 AI 시스템)의 예

  • 규칙 기반 시스템 — 사람이 규칙을 직접 코딩
  • 휴리스틱 기반 (최적화) 알고리즘

즉 AI는 반드시 ML을 써야 하는 것이 아닙니다. 이 점이 확인문제로 나옵니다.

기초 교안 p.9~11

왜 ML인가 — 규칙을 코딩하지 않고 학습한다

예제 · 일상 속 ML
  • 유튜브는 어떻게 내 취향을 알아맞힐까?
  • 이메일은 어떻게 스팸/정상을 가려낼까?

공통점: 사람이 모든 규칙을 미리 코딩하지 않아도, 데이터에서 규칙을 학습해 성능을 향상함.

2-1. 데이터 구성요소 — Feature / Label

핵심

머신러닝은 규칙을 직접 코딩하지 않고, 데이터에서 규칙을 학습한다.
데이터(Feature, Label)의 분포와 관계가 머신러닝의 학습 결과를 결정한다.

Feature (피처, 특성)
  • 모델이 예측에 사용하는 입력정보
  • 예측, 판단의 근거/단서
Label (라벨, 목표값)
  • 모델이 예측하려는 정답
  • 학습의 목표값

2-3. 단일 피쳐(1D) 기반 학습 — 참 함수와 측정오차

1D = 1차원. Feature가 하나일 때 머신러닝이 학습하는 가장 단순한 형태입니다.

수식 · 1D 데이터 생성 모형
Incomei = f*(Years of Educationi) + εi
f*
미지의 참 함수 — Feature와 Label 사이의 실제 평균 관계. 직접 관측할 수 없고, 오차가 포함된 데이터(점)만 관측 가능.
ε
측정 오차 — 데이터에는 주로 측정 오차가 섞여 있음. 원인: 측정 기기의 한계, 환경적 요인 등.

따라서, 데이터 = 참 함수 + 오차 (f* + ε)

D = {(Years of Educationi, Incomei)}i=130  — 30명의 (피쳐, 라벨) 쌍

2-5. 학습이란 무엇인가

정의

주어진 데이터에서 정답을 가장 잘 맞출 수 있도록
모델의 규칙을 조금씩 조정해가는 과정

데이터 D  →  가설공간 ℱ  →  선택된 모델 f

학습에 필요한 3가지

1. 데이터 (Data)

  • 학습할 예시들 (학력-수입 쌍 30개)
  • 입력(특성)과 정답(라벨) 쌍으로 된 정답 모음

2. 가설 공간 (ℱ)

  • 선택할 수 있는 모든 후보 함수들의 집합
  • "이 중에서 가장 좋은 함수를 찾아야 해"

3. 선택 기준 (손실 함수)

  • 어떤 함수가 더 좋은지 판단하는 척도
  • 예측값과 실제값의 차이를 측정

학습 과정 5단계

1. 가설공간에서 하나의 함수를 선택
↓
2. 그 함수로 데이터의 모든 예시를 예측
↓
3. 손실함수로 틀린 정도 계산
↓
4. 더 적게 틀리도록 함수의 파라미터 조정
↓
5. 반복하여 최적의 모델 완성

가장 잘 푸는 함수를 찾는 것이 학습

예) "y = ax + b" 형태의 모든 1차 함수를 제시

4-2. 손실 함수 (Loss Function)

정의

모델의 예측이 정답에서 얼마나 벗어났는지를
하나의 숫자로 나타내는 함수

학습이란, 이 숫자가 작아지는 방향으로 모델을 조금씩 고쳐 나가는 과정

문제 유형에 따라 쓰는 손실이 다르다

회귀 → 평균제곱오차 (MSE)
MSE = 1⁄n × Σ ( y − ŷ )²

정답과 예측의 차이를 제곱해서 평균낸 값

많이 틀릴수록 제곱 때문에 손실이 크게 커짐

CE = − Σ y × log( ŷ )

정답 범주에 얼마나 높은 확률을 주었는지 측정

정답을 확신할수록 0에 가까워짐

5-7. 선형회귀 주의사항 — 다중공선성 · 상관 ≠ 인과

먼저 · 검증/테스트셋이 필요한 이유
훈련 데이터에서의 성능
  • 회귀식을 만들 때 최소제곱 해는 훈련 데이터만 보고 계산됨
  • 학습에 사용된 훈련 데이터에서는 (X과 Y의 평균적인 선형관계가 있다면) 적합(fitting)이 잘 되어 있을 것임
  • 그러나 이것은 테스트 성능을 과소평가할 가능성이 높음
테스트 성능 평가 필요
  • 선형회귀도 일반화 성능을 확인하려면 훈련에 사용되지 않은 새로운(테스트) 데이터에 적용해 봐야 함
  • 변수 수가 많거나 고차항을 사용하면 과적합(overfitting) 문제가 여전히 발생할 수 있음
  • 검증/교차검증을 통해서 적절한 적합을 찾을 수 있음 → 07장

다중공선성 — 변수들이 서로 연관되어 있을 때

주의 · 다중공선성이 왜 문제인가
  • 이상적 상황: 변수들이 연관(correlation)되지 않고, 독립적일 때 → 계수 해석이 명확함
  • 문제 상황: 변수들이 서로 연관되어 있다면 → 계수 추정이 불안정해지고 해석에 혼동이 발생할 수 있음
  • 교안 정리: 다중공선성 문제 발생 가능 (변수 간 높은 상관성) → 계수 해석 어려움 / 분산 증가 → 불안정한 추정
가장 중요한 경고

상관관계 ≠ 인과관계

관찰 데이터의 상관관계로 인과 관계를 주장해서는 안 됨.

  • 예로 들었던 광고 데이터는 자연스럽게 인과성이 있는 것처럼 보이지만, 다른 많은 데이터에서 선형 관계를 보인다고 하여 인과 관계가 있는 것이 아님.
  • 예: "아이스크림 소비량"(X) vs "상어에 물리는 사건"(Y) — 둘 다 여름에 증가할 뿐, 아이스크림이 상어 사고를 일으키는 것이 아님.

p(X; β) = eβ0+β1x 1 + eβ0+β1x = 11 + e−(β0+β1x) ,   β = [β0, β1]T

우도란 "현재 확률 함수가
데이터를 얼마나 잘 설명하는지"를 나타낸 지표

그러므로, 모델의 학습은 우도 값을 높여 최대화가 되도록 하는 것이 목표이며 이를 Maximum Likelihood Estimation (MLE)이라 한다.

📐 로지스틱 회귀의 우도 최대화 HARD

① 우도 함수

로지스틱 회귀와 같은 이진 분류 문제에서 우도를 최대화한다.

maximizeβ   ℒ(β) = ∏i:yi=1 p(xi; β)  ·  ∏i:yi=0 ( 1 − p(xj; β) )
참고   p(xi; β) = eβ0+β1xi 1 + eβ0+β1xi
∏
모든 데이터에 대한 곱 — "모든 관측이 동시에 일어날 확률"
y=1인 항
실제로 1이었던 데이터에 대해, 모델이 준 1일 확률 p
y=0인 항
실제로 0이었던 데이터에 대해, 모델이 준 0일 확률 (1 − p)

② 왜 log를 씌우는가

하지만, 위와 같은 곱으로 이뤄진 함수의 경우, β에 대해 미분이 어렵기 때문에 양 변에 log를 취해 곱셈을 더하기로 변환시킨 뒤 log-likelihood를 만들어 최대화한다.

maximizeβ   log ℒ(β) = Σi=1n [ yi log p(xi; β) + (1 − yi) log(1 − p(xi; β)) ]
연결 — Cross Entropy와 같은 식

이 log-likelihood에 마이너스를 붙이면 그대로 교차 엔트로피(Cross Entropy) 손실이 됩니다. 우도를 최대화 = 교차 엔트로피를 최소화. → Cross Entropy 보기

③ log를 씌워도 정말 괜찮은가?

로지스틱 회귀에서 우도(likelihood)를 최대화하는 것인데, log변환을 한 log-likelihood를 최대화 하는 것으로 변형하여 문제를 접근해도 과연 괜찮을까?

  • Log함수는 단조(monotone) 증가 함수임.
  • 따라서, log-likelihood를 최대화하는 β와 likelihood를 최대화하는 β는 같다!

④ 어떻게 푸는가

log ℒ(β)를 미분하여 도함수 = 0에 근접하도록 수치적(반복) 최적화를 통해 β들을 찾아 나간다.

연결

선형회귀의 최소제곱법과 달리 깔끔한 공식(closed-form)이 없습니다. 그래서 반복적으로 값을 개선해야 하고, 이 아이디어가 그대로 경사 하강법과 신경망 학습으로 이어집니다.

읽는 법: R² = 0.8이면 "평균으로 찍을 때의 오차 중 80%를 내 모델이 줄였다"는 뜻.

→ 나올 수 있음. 예측값(ŷi)들이 평균값 ȳ보다도 못한다면… (즉, 분자가 분모보다 커지면 R² < 0)

예제 · MSE = (1000만원)²은 좋은 성능의 모델일까?

"평균적으로 1000만원 정도 실제값과 차이가 있다"(MSE) VS "모델이 데이터 변동의 80%를 설명한다"(R²)

  • MSE = (1000만원)² : 모델이 예측한 값이 실제값과 평균적으로 1000만원 정도 오류가 있다
  • R² = 0.8 : 평균값만으로 예측할 때 발생하는 제곱오차의 80%를 줄였다

집값 예측에서 MSE = (1000만원)²라면 좋은지 나쁜지 애매하지만, R² = 0.8이라면 "꽤 좋은 모델"이라는 판단 가능

MSE를 볼 때

  • 구체적인 오차 크기가 중요할 때
  • 실제 손실 비용을 계산할 때

R²를 볼 때

  • 모델 성능을 직관적으로 평가할 때
  • 여러 모델을 비교할 때
  • 모델이 전반적으로 얼마나 좋을지 알고 싶을 때

7-4. 분류 정확도 (Accuracy)

먼저 · 왜 MSE·R²를 못 쓰는가

분류모델은 Label이 범주로 돼 있기 때문에 MSE나 R²를 사용하기 어렵다.

수식 · Accuracy

정확도: 전체 예측 중에서 올바르게 맞춘 예측의 비율

Accuracy = 1⁄n Σi=1n 𝕀( yi = ŷi )   =   올바르게 맞춘 개수전체 예측 개수
𝕀
지시(indicator) 함수. 𝕀(A) = 1 if A true. 조건이 참이면 1, 거짓이면 0을 반환하는 함수
𝕀(y=ŷ)
= 1 if 실제값 = 예측값 (맞춤)
𝕀(y≠ŷ)
= 0 if 실제값 ≠ 예측값 (틀림)
정확도 예시 — 𝕀 (고양이) 분류
  • 실제(yi): 고양이, 예측(ŷi): 고양이 → 𝕀(고양이 = 고양이) = 1 (맞춤)
  • 실제(yi): 고양이, 예측(ŷi): 강아지 → 𝕀(고양이 ≠ 강아지) = 0 (틀림)

기초 교안 p.81

⚠ 정확도의 함정 — 불균형 데이터 문제

정확도가 99%이면 좋은 모델일까?

불균형 데이터(양성 1%, 음성 99%)에서는 전부 음성이라 해도 정확도가 99%로 보일 수 있음

질병 진단 데이터 1000명실제 환자 10명(1%) · 건강 990명(99%)
→
무조건 모든 사람을
"건강하다"고 예측문제가 있는 모델
→
정확도 = 990/1000 = 99%
  • 질병 환자 → "건강"으로 예측 (10개 틀림) / 건강한 환자 → "건강"으로 예측 (990개 맞음)
  • 정확도 99%지만 질병 환자를 전부 놓침
  • 실제로 중요한 "질병 발견" 능력이 전혀 없음

결론: 정확도는 단순히 "전체 중 맞춘 비율"만 계산함. 정확도만 보지 말고 다른 지표(예: 혼동행렬)도 함께 봐야 안전

7-6. 분류 손실: 교차 엔트로피 (Cross Entropy)

문제 제기 · 정확도만 보고 학습할 수 있을까?
  • 정확도·혼동행렬은 학습이 끝난 결과를 "평가"하는 지표
  • 맞음/틀림만 세므로, 예측 확률이 0.51에서 0.95로 좋아져도 값은 그대로임

7-8. 학습의 목적과 과적합(Overfitting)

학습의 목적

훈련 데이터로 학습한 모델이
새로운 데이터에서도 정확한 예측을 수행하도록 하는 것

  • 학습 모델의 성능 평가는 모델이 처음 보는(학습에 사용되지 않은) 데이터로 평가
  • "이 모델이 훈련 상황 외에 새로운 상황에서도 잘 동작 할까?"(일반화) 를 검증
  • 훈련 데이터에서 성능이 아무리 좋아도, 새로운 데이터에서 성능이 떨어지면 실전엔 사용할 수 없음
  • 일반화(generalization) 오류의 최소화 지향 → 새로운 데이터에서 틀리는 걸 최대한 줄여야 한다!

기초 교안 p.89

오버피팅 (Overfitting)

훈련 데이터의 우연한 패턴/잡음까지 외워버려서 훈련에서는 잘 맞지만 테스트에서는 성능이 나빠지는 현상

현상: 훈련 오류 급격히 낮음, 테스트 오류 높음/요동

오버피팅이 왜 안 좋은가?
  • 표본(sample) 의존·불안정: 훈련 데이터는 모집단의 일부 표본이라 우연한 잡음이 섞임. 이 것에만 과하게 맞추어 학습하면 샘플 몇 개만 바뀌어도 예측이 크게 흔들림(분산↑).
  • 일반화 실패: 보지 못한 데이터(테스트) 오류가 커짐, 모(population)집단 성능과 격차가 벌어짐.
⚠ 오해 방지 · 오버피팅 ≠ 분포 변화

오버피팅 ≠ 분포 변화(distribution shift)로 인한 에러 증가

  • 분포 변화로 인한 오류: 훈련 데이터 분포와 테스트 분포가 다름으로 (환경·계절·센서 변경 등) 성능이 떨어지는 현상
  • 분포 변화로 인한 에러 증가는 모델이 과적합하지 않아도 발생 가능

교안의 예: 훈련 데이터는 실제 사진(cat/dog), 테스트 데이터는 일러스트(cat/dog) — 모델 잘못이 아니라 분포가 바뀐 것.

기초 교안 p.92

오버피팅 vs 언더피팅 — 균형 잡기

오버피팅 (Overfitting)

모델이 너무 복잡

→ 잡음까지 학습 (테스트 성능 나쁨)
특징: 훈련 오류 작음, 테스트 오류 큼

언더피팅 (Underfitting)

모델이 단순하거나 학습이 완료되지 않음

→ 중요한 패턴을 놓침 (오류 큼)
특징: 훈련/테스트 모두 오류 큼

  • ⑤ 언더피팅은 복잡도를 높이면 개선 가능하지만, 오버피팅은 오히려 더 심해진다.

7-9. 훈련 오류 vs 테스트 오류

훈련 오류

모델을 학습시킨 같은 데이터에 다시 적용해 계산한 오류

테스트 오류

학습에 쓰지 않은 새 관측치에 대해 모델을 적용했을 때의 평균 예측오류

교안의 비유

훈련 오류 = 문제집 점수  /  테스트 오류 = 시험 점수

문제집만 잘 보면 시험을 잘 본다고 장담할 수 없음!

보통 훈련 오류는 테스트 오류와 다르며, 특히 훈련 오류는 테스트 오류를 (심하게) 과소평가하는 경우가 많음 (예: 암기 vs 응용 시험).

교안의 표현

너무 많이 답을 외우지도(과적합),
너무 대충 공부하지도 않은(과소적합)
딱 적당히 공부해서 점수가 가장 잘 나오는 지점 찾기

💡 Check Point 13 — 훈련 오류와 테스트 오류 (기초 교안 3차시 확인문제 1)
훈련 오류와 테스트 오류에 대한 설명으로 옳은 것은?
  • 훈련 오류는 새로운 데이터에 대한 예측 정확도를 측정한다.
  • 테스트 오류는 학습에 사용된 데이터에 대해 계산한 평균 오차이다.
  • 궁극적으로 테스트 오류를 최소화하는 것이 학습의 목적이다.
  • 일반적으로 훈련 오류는 테스트 오류보다 크게 나타난다.
  • 훈련 오류는 항상 0에 수렴해야 좋은 모델이다.

학습의 목적은 일반화 성능을 높이는 것이며, 이는 테스트 오류를 최소화하는 것이다.

  • ① 새로운 데이터는 테스트 오류가 담당한다.
  • ② 이는 훈련 오류에 대한 설명이다.
  • ④ 일반적으로 훈련 오류 < 테스트 오류이다.
  • ⑤ 훈련 오류가 0에 가까우면 오버피팅일 가능성이 높다.

7-11. K-겹 교차검증 (K-fold Cross-Validation)

정의

테스트 오류 추정의 표준적 접근

문제집을 5등분 해서 서로 다른 모의고사를 5번 보는 것

  • 추정치는 모델 선택과 최종 모델의 테스트 오류 규모 파악에 활용
  • 데이터 전체를 크기 동일한 K개 폴드로 무작위 분할
  • → 폴드 k ∈ {1,2,…,K}를 검증, 나머지 K−1개를 훈련에 사용
  • k = 1,…,K에 대해 반복 후, 평균 오류로 테스트 오류를 추정

K-겹 교차검증 단계

  1. 데이터를 먼저 셔플링한 뒤, 총 n개의 데이터를 겹치지 않는 K개 그룹으로 분할
  2. 각 그룹이 번갈아 검증셋(주황), 나머지는 훈련셋(파랑)
  3. K개의 MSE를 평균해 테스트 오류를 추정
1번째: 폴드1이 검증, 나머지가 훈련
수식 · K-겹 교차검증 오류 계산

폴드 집합 C1, …, CK, 각 폴드 크기 nk

CV(K) = Σk=1K nkn MSEk
여기서, MSEk = 1⁄nk Σi∈Ck ( yi − ŷi )²
MSEk
K-폴드를 검증셋으로 두고 나머지로 적합한 예측 ŷi로 계산한 오차
MSE(평균제곱오차): 예측이 얼마나 틀렸는지를 숫자로 표현한 값 (오차를 제곱해 평균)
nk/n
폴드 크기에 비례한 가중 평균

Leave-One-Out 교차검증 (LOOCV)

K = n이면 Leave-One-Out 교차검증(LOOCV) — 100개 문제(n)로 100개의 서로 다른 모의고사(K)를 만드는 것.

  • 훈련셋(파랑): 관측치 하나만 제외한 나머지 전부
  • 검증셋(주황): 제외한 1개 관측치
  • 이 과정을 n번 반복해 나온 n개의 MSE 평균으로 테스트 오류를 추정

  • 두 방법의 경향과 최적 차수가 비슷
  • LOOCV는 모든 데이터를 검증에 사용. 하지만 연산량이 많아서 학습 시간이 오래 걸림

11-2. K-means 클러스터링

수식 · K-means의 표기(군집 집합)

관측치 인덱스 집합을 C1, …, CK 라 하면:

C1 ∪ ⋯ ∪ CK = {1, …, n}  (각 관측치는 적어도 하나의 군집에 속함)
모든 다른 클러스터 k ≠ k′ 에 대해,   Ck ∩ Ck′ = ∅

→ 하나의 데이터가 여러 그룹에 동시에 속할 수 없음

i번째가 k번째 군집이면   i ∈ Ck  (비중첩 분할)

모든 데이터를 겹치지 않게(K개 군집이 서로 겹치지 않음), 빠짐없이(K개 군집 중 하나에는 반드시 포함), 정확히 하나의 군집에만 나눔

핵심 아이디어
  • 좋은 군집화 = 클러스터 내부 변동(Within-Cluster Variation)이 작은 분할
  • 목표: 클러스터 거리·차이의 합이 최소가 되도록 데이터를 나누는 것

11-4. 계층적 군집 (Hierarchical Clustering)

K-means vs 계층적 군집
  • K-means는 클러스터 수 K를 미리 지정해야 하는 단점이 존재함
  • 계층적 군집은 K를 고정하지 않고 전체 구조를 덴드로그램으로 제공
  • 이번 강의에서는 상향식(agglomerative)을 다룸: 잎 → 몸통으로 병합

계층적 군집 알고리즘 (상향식)

n개 관측에 대해 쌍별 비유사도 계산, 각 관측치를 하나의 클러스터로 시작
→
i개 클러스터 간 쌍별 비유사도를 모두 계산해 가장 유사한 두 클러스터를 병합
→
병합 후 남은 i−1개 클러스터 사이의 새 비유사도를 다시 계산

↺ i = n, n−1, …, 2에 대해 반복

  • 클러스터 수 K를 미리 지정해야 한다.
  • 덴드로그램(Dendrogram)을 통해 전체 구조를 시각적으로 제공한다.
  • 데이터 간 병합(상향식) 과정을 통해 클러스터를 형성한다.
  • 클러스터 내부 변동(Within-cluster variation)의 합이 최소가 되도록 분할한다.
  • 매우 큰 데이터셋에도 계산 복잡도가 크게 늘지 않아 효율적이다.
정답 — K-means: A, D, E  /  계층적 군집: B, C

K-means는 데이터를 K개의 그룹으로 나누는 대표적 기법으로, 군집 내 분산을 최소화하도록 반복 계산한다. 빠르고 대규모 데이터에 효율적이지만 클러스터 수를 미리 지정해야 하고 복잡한 모양의 데이터에는 한계가 있다.

계층적 군집은 데이터를 병합·분할하여 트리(덴드로그램) 구조를 만드는 방식으로, 클러스터 수를 미리 정하지 않아도 되고 데이터 구조를 시각적으로 파악하기 쉽다. 그러나 데이터가 많을수록 계산 비용이 커져 대규모 데이터에는 비효율적이다.
