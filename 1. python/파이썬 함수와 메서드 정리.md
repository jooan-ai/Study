# 파이썬 주요 메서드 및 내장 함수 정리

## 1. 반환값이 없는 메서드 (In-place 수정 / `None` 반환)

이 메서드들은 실행하면 **원본 데이터를 직접 수정**하며, 함수 자체의 실행 결과는 `None`을 반환합니다.

따라서 `result = a.append(1)` 처럼 변수에 저장하면 안 되고, 그냥 `a.append(1)` 형태로 실행해야 합니다.

### ① 리스트 (List) 메서드

* **`list.append(x)`**: 리스트 맨 끝에 요소 `x`를 추가
* **`list.extend(iterable)`**: 리스트 끝에 다른 이터러블(리스트, 튜플 등)을 이어 붙임
* **`list.insert(i, x)`**: `i`번 인덱스 위치에 요소 `x`를 삽입
* **`list.remove(x)`**: 리스트에서 값이 `x`인 첫 번째 항목을 삭제
* **`list.clear()`**: 리스트의 모든 요소를 지움 (빈 리스트로 만듦)
* **`list.sort(key=..., reverse=...)`**: 리스트 자체를 **그 자리에서 정렬**
* **`list.reverse()`**: 리스트의 요소 순서를 **그 자리에서 뒤집음**

### ② 세트 (Set) 메서드

* **`set.add(x)`**: 세트에 요소 `x`를 추가
* **`set.update(*others)`**: 세트에 여러 요소를 한 번에 추가
* **`set.remove(x)`**: 세트에서 `x`를 제거 (없으면 `KeyError` 발생)
* **`set.discard(x)`**: 세트에서 `x`를 제거 (없어도 에러 발생 안 함)
* **`set.clear()`**: 세트의 모든 요소를 지움
* **`set.intersection_update(*others)`**: 다른 세트들과의 교집합 요소만 원본에 남김 (`&=`)
* **`set.difference_update(*others)`**: 다른 세트들과의 차집합 결과만 원본에 남김 (`-=`)
* **`set.symmetric_difference_update(other)`**: 대칭차집합 결과를 원본에 남김 (`^=`)

### ③ 딕셔너리 (Dictionary) 메서드

* **`dict.update([other])`**: 다른 딕셔너리나 `(키, 값)` 쌍으로 기존 딕셔너리를 덮어쓰거나 추가
* **`dict.clear()`**: 딕셔너리의 모든 키-값 쌍을 지움

## 2. 반환값이 있는 메서드 및 내장 함수 (새로운 값 반환)

이 함수/메서드들은 **원본 데이터를 절대로 변경하지 않으며**, 계산되거나 변환된 **새로운 결과값(숫자, 문자열, 리스트, 튜플 등)을 반환**합니다.

따라서 결과를 활용하려면 `result = sorted(a)` 처럼 **변수에 할당**하여 사용해야 합니다.

### ① 파이썬 주요 내장 함수 (Built-in Functions)

* **`sorted(iterable, key=..., reverse=...)`**: 정렬된 **새로운 리스트** 반환 *(원본 유지)*
* **`reversed(seq)`**: 순서가 뒤집힌 **새로운 이터레이터** 반환
* **`len(s)`**: 데이터의 **길이(요소 개수)** 반환
* **`sum(iterable, start=0)`**: 요소들의 **총합** 반환
* **`max(arg1, arg2, ...)` / `min(arg1, arg2, ...)`**: **최댓값 / 최솟값** 반환
* **`abs(x)`**: **절댓값** 반환
* **`round(number, ndigits)`**: **반올림한 값** 반환
* **`type(object)`**: 객체의 **자료형** 반환
* **`id(object)`**: 객체의 **고유 메모리 주소** 반환
* **`enumerate(iterable)`**: `(인덱스, 값)` 형태의 **튜플 이터레이터** 반환
* **`zip(*iterables)`**: 여러 이터러블의 요소를 묶은 **튜플 이터레이터** 반환
* **`map(function, iterable)`**: 각 요소에 함수를 적용한 **새로운 이터레이터** 반환
* **`filter(function, iterable)`**: 조건 함수가 참(`True`)인 요소만 남긴 **새로운 이터레이터** 반환
* **`all(iterable)`**: 모든 요소가 참이면 `True` 반환
* **`any(iterable)`**: 하나라도 참이면 `True` 반환
* **`isinstance(object, classinfo)`**: 객체가 해당 클래스/자료형의 인스턴스인지 여부(`True`/`False`) 반환
* **`hasattr(object, name)`**: 객체에 특정 속성이 있는지 여부(`True`/`False`) 반환

### ② 문자열 (String) 메서드

> 💡 **문자열은 수정 불가능(Immutable)한 자료형이므로, 모든 문자열 메서드는 100% 반환값을 가집니다.**

* **변환 관련**
  * **`str.lower()` / `str.upper()`**: 소문자 / 대문자로 변환된 **새 문자열**
  * **`str.strip([chars])` / `lstrip()` / `rstrip()`**: 공백이나 특정 문자가 제거된 **새 문자열**
  * **`str.replace(old, new)`**: 문자열 치환된 **새 문자열**
  * **`str.title()` / `str.capitalize()`**: 첫 글자 대문자화된 **새 문자열**
  * **`str.join(iterable)`**: 이터러블 요소들을 연결한 **새 문자열**

* **분리 및 검색 관련**
  * **`str.split(sep=None, maxsplit=-1)`**: 구분자로 나눈 **새 리스트**
  * **`str.find(sub)` / `str.rfind(sub)`**: 문자의 **인덱스 위치** 반환 (없으면 `-1`)
  * **`str.index(sub)` / `str.rindex(sub)`**: 문자의 **인덱스 위치** 반환 (없으면 에러)
  * **`str.count(sub)`**: 특정 문자열의 **개수** 반환

* **검증 (Bool 반환)**
  * **`str.startswith(prefix)` / `str.endswith(suffix)`**: 특정 문자로 시작/끝나는지 (`True`/`False`)
  * **`str.isdigit()` / `str.isalpha()` / `str.isalnum()` / `str.isspace()`**: 숫자/알파벳/조합/공백 여부 (`True`/`False`)

### ③ 리스트 (List) - 조회/삭제 후 반환 메서드

* **`list.pop([i])`**: `i`번째 요소를 **삭제하면서 그 값을 반환** *(원본도 수정됨)*
* **`list.index(x)`**: 값 `x`가 있는 첫 번째 **인덱스 번호** 반환
* **`list.count(x)`**: 값 `x`가 몇 개 들어있는지 **개수** 반환
* **`list.copy()`**: 리스트의 **얕은 복사본(새 리스트)** 반환

### ④ 딕셔너리 (Dictionary) 메서드

* **`dict.get(key, default=None)`**: 키에 해당하는 **값(Value)** 반환 (키가 없어도 에러 안 남)
* **`dict.keys()`**: 모든 키들을 담은 **dict_keys 객체** 반환
* **`dict.values()`**: 모든 값들을 담은 **dict_values 객체** 반환
* **`dict.items()`**: 모든 (키, 값) 쌍을 담은 **dict_items 객체** 반환
* **`dict.pop(key[, default])`**: `key`에 해당하는 항목을 **삭제하면서 그 값(Value)을 반환** *(원본 수정됨, key가 없으면 `default` 반환/설정 안 되어 있으면 `KeyError`)*
* **`dict.popitem()`**: 딕셔너리에서 마지막으로 추가된 **(키, 값) 튜플을 삭제하면서 반환** *(Python 3.7+ 기준 LIFO 방식, 원본 수정됨)*
* **`dict.setdefault(key[, default])`**: `key`가 존재하면 해당 **값을 반환**, 없으면 `key: default`를 **딕셔너리에 추가하고 `default` 값을 반환** *(원본 수정 가능)*
* **`dict.copy()`**: 딕셔너리의 **얕은 복사본(새 딕셔너리)** 반환

### ⑤ 세트 (Set) 메서드

* **`set.pop()`**: 세트에서 임의의 요소를 **하나 꺼내서 삭제하고 그 값을 반환** *(비어있으면 `KeyError`, 원본 수정됨)*
* **`set.union(*others)`**: 합집합 **새 세트** 반환 (`|`)
* **`set.intersection(*others)`**: 교집합 **새 세트** 반환 (`&`)
* **`set.difference(*others)`**: 차집합 **새 세트** 반환 (`-`)
* **`set.symmetric_difference(other)`**: 대칭차집합 **새 세트** 반환 (`^`)
* **`set.issubset(other)`**: 부분집합 여부 반환 (`True`/`False`)
* **`set.issuperset(other)`**: 상위집합 여부 반환 (`True`/`False`)
* **`set.isdisjoint(other)`**: 서로소(교집합이 없음) 여부 반환 (`True`/`False`)
* **`set.copy()`**: 세트의 **얕은 복사본(새 세트)** 반환

### ⑥ 튜플 (Tuple) 메서드

> 💡 **튜플은 불변(Immutable) 객체이므로 원본 변경 메서드가 없으며, 데이터 조회 기능만 제공합니다.**

* **`tuple.index(x)`**: 값 `x`가 위치한 첫 번째 **인덱스 번호** 반환
* **`tuple.count(x)`**: 값 `x`가 튜플 내에 몇 개 있는지 **개수** 반환
