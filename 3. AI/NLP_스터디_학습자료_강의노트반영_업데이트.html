토큰화Tokenization

자료 범위 확인 정리자료 p.1·4의 목차 / 강의노트에는 독립 정의 없음
토큰화: 텍스트 → 토큰 → 토큰 ID
세부 tokenizer 규칙은 자료 범위 밖
그림 한 줄 요약 · 토큰화 그림은 특정 알고리즘을 가정하지 않고 텍스트가 토큰 시퀀스와 정수 ID로 바뀌는 최소 흐름만 보여줍니다.
그림 읽는 순서
  1. 원문 텍스트를 입력합니다.
  2. Tokenizer가 텍스트를 처리 단위인 토큰으로 나눕니다.
  3. 토큰 시퀀스가 만들어집니다.
  4. 각 토큰을 vocabulary의 정수 ID로 연결합니다.
헷갈림 방지 · 원자료는 토큰화 세부 알고리즘을 정의하지 않습니다. 따라서 WordPiece의 “##”처럼 특정 알고리즘 표기를 정답처럼 보여주지 않았습니다.

먼저 알아둘 자료 범위

제공된 자료는 “토큰화 → 인코딩”의 순서를 목차에 제시하지만, 토큰화 자체의 정의·세부 알고리즘을 독립적으로 설명하는 본문은 충분히 제공하지 않습니다. 따라서 이 장에서는 자료에 없는 BPE·WordPiece 같은 내용을 임의로 보충하지 않고, 다음 장의 인코딩으로 넘어가기 위한 위치만 확인합니다.

핵심 개념 요약

정리자료의 목차에서 토큰화는 인코딩보다 먼저 배치되어 있습니다.

하지만 첨부 자료만으로는 “어떤 기준으로 텍스트를 토큰으로 나누는가”를 세부적으로 정답화할 근거가 부족합니다.

스터디에서는 이 장을 “숫자로 표현하기 전에 텍스트의 처리 단위가 필요하다”는 연결 지점으로만 사용하고, 구체적인 토큰화 기법은 이번 자료 범위 밖으로 두는 것이 안전합니다.

02

인코딩One-hot Encoding → Word Embedding → Word2Vec

교재 기준 p.10–21 · 보완 정리자료 p.4–6 · 비교 강의노트 p.1
인코딩과 Word2Vec: 표현 방식 + 예측 방향
Skip-gram: 중심→주변 · CBOW: 주변→중심
그림 한 줄 요약 · Word2Vec의 두 학습 방식은 예측 방향이 정확히 반대이며, 라벨을 “중심 단어/주변 단어”로 통일했습니다.
그림 읽는 순서
  1. One-hot은 단어를 서로 다른 희소 벡터로 구분합니다.
  2. Word Embedding은 밀집된 연속 벡터로 의미 관계를 표현합니다.
  3. Skip-gram은 중심 단어를 입력으로 주변 단어를 예측합니다.
  4. CBOW는 주변 단어들을 입력으로 모아 SUM/Projection 표현을 만든 뒤 중심 단어를 예측합니다.
헷갈림 방지 · Skip-gram/CBOW의 핵심 차이는 “무엇이 입력이고 무엇이 출력인가”입니다. 두 방향을 같은 선으로 연결하지 말고 화살표로 반대로 보여야 합니다.

핵심 개념 요약

원-핫 인코딩은 단어를 서로 구분되는 원자적 기호처럼 다루고, 어휘 집합 크기만큼의 차원 중 해당 단어 위치 하나만 1, 나머지는 0으로 표현합니다. 즉 원-핫 벡터는 “이 단어가 누구인지”는 구분하지만, 단어 사이의 의미 관계까지 알려주지는 않습니다.

어휘가 커지면 차원도 함께 커지고 대부분이 0인 희소 벡터가 되므로 차원의 저주가 나타납니다. 또 서로 다른 원-핫 벡터는 직교하므로 “핸드폰–스마트폰”처럼 의미가 가까워도 벡터 공간에서는 가까움을 표현하기 어렵습니다.

워드 임베딩은 단어를 고정 길이의 밀집된 실수 벡터로 학습해 비슷한 문맥의 단어가 비슷한 표현을 갖게 합니다. 비유하면 원-핫이 “사전의 주소표”라면 임베딩은 “단어의 성격을 여러 축으로 요약한 좌표”에 가깝습니다.

Word2Vec은 중심 단어와 주변 단어의 관계를 예측하며 표현을 학습합니다. Skip-gram은 중심→주변, CBOW는 주변→중심 방향이며, 교재의 CBOW 그림은 여러 주변 입력을 SUM하여 projection 표현을 만든 뒤 중심 단어를 예측하는 흐름을 보여줍니다.

핵심 개념 요약

순차적 데이터는 입력되는 순서와, 그 순서를 통해 형성되는 데이터 사이의 관계가 중요한 데이터입니다.

언어에서는 단어 순서가 바뀌면 의미가 달라질 수 있고, 멀리 떨어진 과거 정보가 현재/미래 해석에 영향을 주는 장기 의존성이 있습니다. 또한 문장마다 길이가 달라 가변 길이를 처리해야 합니다.

교재가 MLP/CNN과 대비해 강조하는 지점은 “NLP 자체를 못 한다”가 아니라, 전통적인 형태는 고정 길이 입력을 전제로 하므로 가변 길이 순차 데이터를 자연스럽게 처리하기 어렵다는 점입니다.

이 문제를 다루기 위해 RNN, LSTM, Transformer 같은 Sequential Model로 이어집니다.

RNN / LSTM기억을 전달하는 RNN → 기억을 선택하는 LSTM

교재 기준 p.27–42 · 보완 정리자료 p.7–13 · 비교 강의노트 p.2–3
RNN과 LSTM: hidden state 전달과 선택적 기억 갱신
LSTM 게이트는 직렬 3단계가 아님
그림 한 줄 요약 · LSTM은 세 게이트를 직렬 통과하는 구조가 아니라, gate 값으로 cell state와 hidden state를 선택적으로 갱신하는 RNN 변형입니다.
그림 읽는 순서
  1. RNN은 현재 입력과 이전 hidden state로 새 hidden state를 만들고 다음 시점으로 넘깁니다.
  2. LSTM은 같은 현재 입력/이전 hidden state에서 Forget/Input/Output gate 값을 계산합니다.
  3. Forget Gate가 이전 Cₜ₋₁을 조절하고, Input Gate iₜ와 새 cell 후보 C̃ₜ의 곱을 더해 Cₜ를 갱신합니다.
  4. Output gate가 Cₜ에서 얼마나 hidden state hₜ로 내보낼지 결정합니다.
헷갈림 방지 · Forget→Input→Output을 일렬 파이프처럼 그리면 세 게이트를 순차 통과한다고 오해하기 쉽습니다. 게이트 값은 같은 시점의 입력에서 계산되어 서로 다른 역할로 상태 갱신에 참여합니다.
추가 체크 · gate는 하나의 스위치가 아니라 여러 차원의 0~1 벡터이며, 각 차원마다 정보 통과량을 다르게 조절합니다.

핵심 개념 요약

RNN은 현재 입력 xₜ와 이전 hidden state hₜ₋₁을 함께 사용해 새로운 hₜ를 만들고 다음 시점으로 전달합니다. 시간축에 펼쳐 보면 같은 RNN cell이 반복되며, 각 시점이 같은 가중치를 공유하므로 파라미터 효율적입니다.

학습할 때는 펼쳐진 시간축을 따라 오차가 뒤로 전달됩니다. 교재는 이 역전파에서 작은 미분값이 반복해서 곱해지면 과거로 갈수록 기울기가 작아져 Vanishing Gradient가 생기고, 장기 의존성을 배우기 어려워진다고 설명합니다.

LSTM은 hidden state와 별도로 cell state를 두고, Forget/Input/Output Gate로 “과거 중 무엇을 유지할지, 새 정보 중 무엇을 기록할지, 현재 무엇을 밖으로 보낼지”를 선택합니다.

각 gate는 같은 (hₜ₋₁, xₜ) 문맥에서 계산되며, 0~1 사이의 벡터 값으로 정보 흐름을 원소별(element-wise) 조절합니다.

이렇게 이해하면 더 쉬워요

RNN unfolding은 “여러 사람이 릴레이하는 것”보다 한 사람이 같은 규칙을 들고 시간별로 반복 작업하는 것에 가깝습니다. 그림에서 cell이 여러 개 보여도 파라미터는 시간마다 새로 생기는 것이 아니라 같은 가중치를 공유합니다.

LSTM의 cell state는 긴 컨베이어 벨트, gate는 각 정보 차원마다 달린 조절 밸브라고 생각해보세요. Forget/Input/Output을 세 칸짜리 직렬 통로로 생각하기보다, 같은 시점에 서로 다른 역할을 수행하는 조절 장치로 보는 편이 정확합니다.

BPTT 표기 메모 · 새 노트의 Backpropagation Through Time(BPTT)은 RNN 학습을 설명하는 표준 용어입니다. 다만 교재 본문은 이름 자체보다 “시간축으로 펼친 네트워크에서 역전파하며 작은 값이 반복 곱되어 기울기 소실이 생긴다”는 현상을 중심으로 설명하므로, 이번 자료에서도 BPTT는 보조 용어로만 사용합니다.

장점은 단순하지만, 고려하는 문맥 길이가 제한되어 긴 의존성을 반영하기 어렵습니다.

NMT / Seq2SeqNeural Machine Translation & Sequence-to-Sequence

교재 기준 p.67–74 · 보완 정리자료 p.15–18 · 비교 강의노트 p.3–4
Seq2Seq: Encoder → 고정 Context → Decoder 순차 생성
<SOS> 시작 · <EOS> 종료
그림 한 줄 요약 · 기본 Seq2Seq는 입력 시퀀스를 하나의 고정 Context(교재 예시는 마지막 hidden state)로 요약하고, Decoder가 이를 바탕으로 토큰을 순차 생성합니다.
그림 읽는 순서
  1. Encoder가 입력 토큰을 순서대로 읽어 hidden state를 갱신합니다.
  2. 기본 Seq2Seq의 교재 예시에서는 마지막 encoder hidden state가 고정 길이 Context 역할을 해 Decoder로 전달됩니다.
  3. Decoder는 <SOS>에서 시작해 토큰을 한 개씩 생성합니다.
  4. <EOS>가 나오면 출력을 끝냅니다.
헷갈림 방지 · Decoder를 s₁ 하나만 그리면 “출력도 한 번에 나온다”고 오해할 수 있습니다. 여러 시점과 토큰 생성 방향을 보여줘야 합니다.

핵심 개념 요약

NMT는 신경망으로 기계 번역을 수행하는 방법이며, 이 강의에서는 서로 다른 길이의 입력·출력 시퀀스를 연결하기 위해 Seq2Seq Encoder–Decoder 구조를 사용합니다.

Encoder는 입력 문장을 순서대로 읽어 고정 차원의 Context 표현으로 요약하고, Decoder는 그 표현을 바탕으로 <SOS>에서 시작해 출력 문장을 한 토큰씩 생성합니다. 교재 p.69의 기본 예시는 F(h₁,…,h₇)=h₇, 즉 마지막 encoder hidden state가 Context 역할을 하는 경우입니다.

학습에서는 Teacher Forcing으로 이전 시점의 정답 토큰을 Decoder 입력에 넣어 학습을 안정화할 수 있습니다. 추론에서는 Greedy가 매 단계 최고 확률 토큰을 선택하고, Beam Search는 k개의 유망 후보를 유지하며 누적 로그 확률 점수로 최종 문장을 고릅니다.

여기서 모든 encoder hidden state를 직접 활용하는 아이디어는 다음 장 Attention에서 등장합니다. 기본 Seq2Seq와 Attention을 이 지점에서 구분해두면 구조가 훨씬 명확해집니다.

Beam candidate score ≈ Σₜ log P(yₜ | y₍<t₎, x) 교재 p.74: 각 단계에서 유망 후보를 유지하고, 후보 문장의 점수를 로그 확률의 합으로 비교합니다.

이렇게 이해하면 더 쉬워요

기본 Seq2Seq의 Context Vector = 여행가방 하나라고 생각해보세요. Encoder가 입력 문장의 정보를 한 가방에 압축해서 Decoder에게 건넵니다. 문장이 길어질수록 한 가방에 모두 넣기 어려워지는 것이 bottleneck입니다.

다음 장의 Attention은 “가방 하나만 넘겨주기” 대신 Decoder가 필요할 때마다 Encoder의 여러 기록을 다시 펼쳐보고 필요한 부분을 골라 쓰는 방식입니다.

Query = decoder state · Values = encoder states
그림 한 줄 요약 · Attention의 핵심은 decoder Query가 매 시점 encoder의 모든 hidden state에 서로 다른 weight를 주고 가중합하여 context vector를 만드는 것입니다.
그림 읽는 순서

  3. 각 encoder hidden state hᵢ에 αᵢ를 곱해 모두 더합니다.

헷갈림 방지 · Weight 숫자만 나열하고 Context로 한 줄만 연결하면 “어떤 hᵢ가 어떻게 섞이는지”가 보이지 않습니다. αᵢ·hᵢ가 합쳐지는 경로를 직접 그려야 합니다.

핵심 개념 요약

초기 Seq2Seq는 입력 전체를 하나의 고정 길이 벡터로 압축해 Decoder에 넘기므로 긴 문장에서 정보가 손실되는 bottleneck problem이 생길 수 있습니다.

Attention은 현재 Decoder hidden state를 Query로 보고, Encoder의 모든 hidden state와 관련성 score를 계산합니다. Score를 Softmax로 바꾼 값 α가 “이번 출력 위치에서 각 입력 위치를 얼마나 볼지”를 나타내는 Attention distribution입니다.

각 Encoder hidden state hᵢ를 αₜ,ᵢ만큼 가중해 더하면 현재 Decoder 시점의 Context Vector가 됩니다. 즉 Context는 매 출력 시점마다 다시 계산되어 참고 위치가 달라집니다.

이 분포가 입력 위치와 출력 위치 사이의 대응을 형성하므로 Alignment를 자연스럽게 학습할 수 있고, Decoder가 모든 Encoder hidden state에 직접 접근해 긴 입력의 정보 손실을 완화합니다.

핵심 개념 요약

RNN은 정보가 시간 순서대로 전달되어 먼 단어끼리 상호작용하려면 여러 단계를 거쳐야 하고, 순차 계산 때문에 병렬화가 어렵습니다. Self-Attention은 한 시퀀스 내부에서 각 토큰이 다른 토큰과 직접 관계를 계산합니다.

같은 입력 표현 X에서 서로 다른 학습 가능한 선형 변환 W_Q, W_K, W_V를 적용해 Query, Key, Value를 만듭니다. Query가 모든 Key와 score를 계산하고, Softmax 가중치로 Value를 섞어 각 토큰의 새 표현을 만듭니다.

중요한 점은 Q/K/V가 같은 입력에서 나오더라도 W_Q = W_K = W_V로 같은 파라미터를 공유한다는 뜻은 아니라는 것입니다. 각각 “무엇을 찾을지 / 어떤 표지를 가질지 / 실제 어떤 내용을 전달할지”를 다른 투영으로 학습합니다.

교재가 말하는 순서 정보 부재·비선형성 부족·미래 참조 문제는 완성된 Transformer 전체의 결함이라기보다 bare Self-Attention만 놓고 본 한계이며, Positional Encoding, Feed-Forward Network, Masked Self-Attention으로 보완합니다.

핵심 개념 요약

Transformer는 RNN/LSTM의 시간축 recurrence 대신 Self-Attention을 핵심 메커니즘으로 사용해 시퀀스를 처리합니다. Encoder는 입력의 양방향 문맥 표현을 만들고, Decoder는 미래를 가린 Masked Self-Attention으로 지금까지의 출력만 보며 다음 토큰을 생성합니다.

각 Attention에서 Q/K/V는 입력 표현을 학습 가능한 선형 변환으로 투영해 만들고, Multi-Head Attention은 여러 개의 별도 Head가 서로 다른 관계 관점을 동시에 포착하도록 합니다. Head의 핵심 목적을 단순히 파라미터 절감으로만 이해하지 않는 것이 중요합니다.

큰 내적값을 안정화하는 Scaled Dot-Product, 비선형 변환을 위한 FFN, 깊은 학습을 돕는 Residual Connection과 Layer Normalization이 블록을 이룹니다.

Encoder–Decoder 구조에서는 Cross-Attention에서 Query는 Decoder에서, Key/Value는 Encoder 출력에서 가져와 입력과 출력을 연결합니다.

그림 읽는 순서

  2. BERT는 Encoder-only 구조로 [MASK] 위치를 양방향 문맥에서 예측합니다.
  3. T5는 Encoder-Decoder로 손상된 span을 복원하고, GPT는 Decoder-only로 왼쪽 문맥에서 다음 토큰을 예측합니다.
  4. 학습된 파라미터는 이후 downstream task나 생성에 재사용됩니다.
  5. 사전학습된 파라미터는 이후 downstream task에서 Fine-tuning의 좋은 초기값으로 사용할 수 있습니다.

단계 구분 · Pretraining은 범용 표현 학습, Fine-tuning은 특정 태스크 적응입니다.

핵심 개념 요약

사전학습(Pretraining)은 대규모 텍스트로 모델 전체 파라미터가 일반적인 언어 패턴과 표현을 먼저 익히게 하는 단계입니다. 목적은 특정 태스크의 정답을 바로 외우는 것이 아니라, 이후 여러 NLP 태스크에 재사용할 수 있는 좋은 언어 표현과 초기 파라미터를 얻는 것입니다.

그 다음 Fine-tuning은 사전학습된 파라미터에서 시작해 특정 downstream task에 맞게 추가로 조정하는 단계입니다. 쉽게 말해 Pretraining이 “기초 체력과 언어 감각 만들기”라면 Fine-tuning은 “특정 시험 종목에 맞춰 연습하기”입니다.

교재 p.148은 사전학습 모델을 Encoder / Encoder-Decoder / Decoder 세 계열로 비교하고, p.149–150에서 Encoder 기반 대표인 BERT와 Masked Language Model을 소개합니다.

업로드된 교재 원본은 p.150에서 끝나므로, BERT의 NSP 세부와 T5/GPT의 구체적 사전학습 방식은 2순위 정리자료에서 보완합니다. 정리자료 기준으로 BERT는 MLM+NSP, T5는 Encoder-Decoder+Span Corruption, GPT는 Decoder+Next Token Prediction으로 정리할 수 있습니다.

이렇게 이해하면 더 쉬워요

Pretraining = 언어 전반을 많이 읽어 기초 실력 만들기, Fine-tuning = 그 기초 실력으로 감정분석·질의응답 같은 특정 과목을 추가 연습하기입니다. 둘은 “학습 전/후”가 아니라 학습 목적이 다른 두 단계라고 보는 편이 정확합니다.

출처 경계 · BERT의 MLM 도입은 1순위 교재 p.149–150에서 직접 확인됩니다. NSP, T5 Span Corruption, GPT의 세부 학습 목표는 현재 업로드된 교재 원본의 p.150 이후가 존재하지 않아 2순위 정리자료로 보완한 내용입니다.
